# Upstream sources

- KlipperPhonesLinux: <https://github.com/umeiko/KlipperPhonesLinux>
- msm8953 Linux kernel: <https://github.com/msm8953-mainline/linux>
- postmarketOS lk2nd images: <https://images.postmarketos.org/>
- postmarketOS packages: <https://pkgs.postmarketos.org/>
- Debian 13: <https://www.debian.org/releases/trixie/>

Release 中的 boot 镜像包含 postmarketOS MSM8953 内核、Xiaomi mido DTB 和 Debian initramfs；rootfs 使用 Debian 13 ARM64 软件包。
